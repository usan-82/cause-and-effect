# ism-simple 조사 기록

`ism-simple`(사상의 분기점, 쉽게 읽기) 각 장을 쓰기 전에 한 근거 조사의 원본 기록이다. 장마다 연 출처 전체, 그대로 옮긴 인용, 초안에서 고친 것, 쓰지 않은 것이 들어 있다. 본문이 실제로 기대는 것만 추린 표는 [`research/04-사상-분기점-근거.md`](../../../research/04-사상-분기점-근거.md)에 있다.

- 조사는 2026-11-13에 AI가 했다. 인용은 내려받은 원문과 프로그램으로 대조했지만 사람이 따로 확인한 것은 아니다.
- 기록 안의 "초안"은 조사 전에 세운 사슬 초안을 말한다. 본문은 이 기록에 맞춰 고쳐 썼다.
- 산업혁명 장의 근거는 `research/04` 안에 바로 적혀 있어 따로 파일이 없다.
