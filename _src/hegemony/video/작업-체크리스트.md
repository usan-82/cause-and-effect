# 영상 만들기 체크리스트 (파일럿 1·2편)

작성자가 챙길 일(☐)과 이 세션이 할 일(→)을 단계별로 나눴다. 위에서부터 차례로 한다. 2026-11-14 기준.

## 한눈에

| 단계 | 작성자 | 이 세션 | 상태 |
|---|---|---|---|
| 1. 콘티 | 읽고 승인하거나 고칠 곳 알려 주기 | 고쳐 쓰기 | 1·2편 검토 대기 |
| 2. 그림 | 그림 도구로 뽑아 올리기 | 지시문 쓰기, 검수, 지도·카드 컷 만들기 | 지시문 준비됨 |
| 3. 음성 | 목소리 고르기, 들어 보고 판단 | 세 언어 해설 만들기 | 견본 나옴 |
| 4. 영상 이어 붙이기 | 초벌 보기, 중학생에게 보여 주기 | 그림·지도·카드·음성·자막 이어 붙이기 | 그림 기다림 |
| 5. 올리기 | 클라우드플레어 계정과 R2 준비 | 공개 페이지 만들기 | 아직 |
| 6. 공개 전 확인 | 마지막 확인 | 근거·고지 점검 | 아직 |

## 1. 콘티

- ☐ [1편 정화](ep01.md)와 [2편 다 가마](ep02.md)의 해설 칸을 처음부터 끝까지 읽는다. 각 3분 40초, 3분 50초 분량이다.
- ☐ 각 편 아래 "검토할 때 봐 주세요"를 본다.
- ☐ 승인하거나, 고칠 곳을 알려 준다.
- → 고친 내용을 콘티, 그림 지시문, 근거 파일에 함께 반영한다.

콘티가 바뀌면 그림도 바뀌므로, 컷 그림은 콘티를 승인한 뒤에 뽑는다. 설정화는 콘티와 상관없어서 지금 뽑아도 된다.

## 2. 그림

### 2-1. 설정화 (먼저)

- ☐ 그림 도구(ChatGPT 또는 제미나이)를 고른다. 같은 지시문으로 둘 다 뽑아 보고 정해도 된다.
- ☐ [1편 지시문](ep01.prompts.md)의 "설정화 A — 정화", [2편 지시문](ep02.prompts.md)의 "설정화 B — 바스쿠 다 가마" 아래 회색 상자를 통째로 복사해 붙여 넣는다. 다른 말은 덧붙이지 않는다.
- ☐ 세로나 정사각형으로 나오면 "가로로 긴 그림으로 다시 그려 줘"라고 한다.
- ☐ 마음에 드는 한 장씩을 `ep01_sheetA.png`, `ep02_sheetB.png`로 저장한다.
- ☐ 아래 "올리는 법"대로 올린다.
- → 검수한다. 시대에 안 맞는 옷, 글자, 수염, 십자가 위치 등을 본다.
- ☐ 그림체와 얼굴을 승인한다. 승인한 설정화가 모든 컷의 기준이 된다.

### 2-2. 컷 그림 (콘티 승인 뒤)

- ☐ 1편 12장, 2편 10장을 뽑는다. 지시문의 "참고 이미지"에 설정화가 적힌 컷은 그 그림 파일을 먼저 올리고 지시문을 붙여 넣는다.
- ☐ 파일 이름은 `ep01_c04.png`처럼 편 번호와 컷 번호(두 자리)로 적는다.
- ☐ 각 지시문의 "검수할 때 볼 것"을 보고 다시 뽑을지 정한다. 특히 그림 안에 글자처럼 생긴 무늬가 생기면 다시 뽑는다.
- → 올라온 그림을 검수하고, 고칠 그림과 그 이유를 알려 준다.
- → 지도 컷과 카드 컷은 이 세션이 만든다. 인물 소개 컷(각 편 2번)은 설정화를 잘라 만든다.

### 2-3. 알아 둘 것

- **무료 한도:** ChatGPT 무료는 하루 두세 장쯤이라고 알려져 있다(공식 숫자 없음). 두 편 24장에 다시 뽑는 것까지 치면 2주쯤 걸릴 수 있다. 제미나이는 한도가 더 넉넉하다는 글이 있다.
- **사용 조건:** 고른 그림 도구의 이용 약관에서, 만든 그림을 공개 영상과 웹사이트에 써도 되는지 한 번 확인한다.
- **원본 보관:** 뽑은 그림의 원본 파일은 내 컴퓨터에도 남겨 둔다.

### 2-4. 올리는 법 (GitHub 웹)

1. https://github.com/usan-82/cause-and-effect 에 들어간다.
2. 왼쪽 위 브랜치 선택에서 `hegemony-video-assets`를 고른다.
3. `_src/hegemony/video/assets/ep01/`(1편) 또는 `assets/ep02/`(2편) 폴더로 들어간다.
4. Add file → Upload files로 그림을 끌어다 놓는다.
5. 아래 Commit changes를 누른다.
6. 이 세션에 "올렸다"고 알려 준다.

## 3. 음성

- ☐ 보내 드린 `voices-ko.mp3`를 듣고 해설 목소리 번호(0~9)를 고른다. 영어·인도네시아어도 같은 번호로 할지 정한다.
- ☐ `sample-ko/en/id.mp3`에서 숫자("1405년", "2만 7천 명", "27,000"), 이름(정화, 윈난, Zheng He), 낯선 낱말(환관)을 어떻게 읽는지 듣는다.
- ☐ 품질이 괜찮은지 정한다. 모자라면 구글 클라우드 TTS로 넘어간다. 그때는 구글 클라우드 결제 계정(카드)과 API 키를 만들어야 한다.
- ☐ 공개 전에 모델 라이선스(OpenRAIL-M) 원문을 PC에서 한 번 읽는다: https://huggingface.co/Supertone/supertonic-3/blob/main/LICENSE
- → 영어·인도네시아어 해설을 번역한다.
- ☐ 인도네시아어 해설은 가능하면 그 언어를 아는 사람에게 한 번 읽혀 본다.
- → 고른 목소리로 두 편의 해설을 세 언어로 만든다. 숫자를 잘못 읽으면 글로 풀어 쓰는 처리를 붙인다.

## 4. 영상 이어 붙이기

- → 그림을 천천히 밀거나 당기는 움직임을 넣는다.
- → 지도 컷과 카드 컷, 해설 음성을 이어 붙여 초벌 영상(mp4)을 만든다.
- → 세 언어 자막 파일(WebVTT)을 만든다. 언어마다 해설 길이가 다르므로(인도네시아어가 한국어보다 40% 길다) 컷 길이를 언어별로 맞춘다.
- ☐ 초벌을 보고 흐름과 속도를 판단한다.
- ☐ **주변 중학생 몇 명에게 보여 준다.** 다 보고 나서 물어볼 것:
  - 어디서 헷갈렸나?
  - 정화(또는 다 가마)는 왜 떠났다고 기억하나?
  - 명은 왜 멈췄고, 포르투갈은 왜 계속 갔다고 기억하나?
  - 지루했던 곳은 어디인가?
- ☐ 들은 내용을 이 세션에 알려 준다.
- → 콘티와 영상을 고친다.
- (선택) `▶` 표시 컷에 움직임을 더하고 싶으면, 그때 힉스필드 같은 유료 영상 생성 도구를 쓴다. 없어도 영상은 완성된다.

## 5. 올리기 (클라우드플레어)

- ☐ 클라우드플레어 계정을 만든다.
- ☐ R2를 켠다. 무료 범위는 저장 공간 10GB다. 가입이나 R2를 켤 때 카드를 요구할 수 있다.
- ☐ 버킷(저장 공간)을 하나 만들고 공개 주소를 켠다.
- ☐ 처음에는 대시보드 화면에서 mp4와 자막 파일을 직접 올린다. 이 세션에서는 클라우드플레어 API 접속이 막혀 있어서, 이 세션이 올리려면 접속 허용과 API 토큰이 필요하다.
- → 세 언어 공개 페이지(`ko/en/id/hegemony/video/`)를 만들어 PR로 올린다.
- ☐ PR을 보고 병합한다.
- (선택) 유튜브에도 올린다. 올릴 때 "아동용" 여부와 AI 생성물 표시를 그때의 유튜브 안내를 보고 정한다.

## 6. 공개 전 확인

- ☐ 영상 끝에 "AI가 그린 상상화" 고지가 있는가
- ☐ 페이지에 근거 파일과 지도 페이지 링크가 있는가
- ☐ 음성 모델 라이선스 원문과 그림 도구 약관을 확인했는가
- → 근거 파일의 `[미확인]` 항목이 해설에 들어가지 않았는지 다시 점검한다.
