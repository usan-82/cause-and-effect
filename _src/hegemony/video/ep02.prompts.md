# 2편 그림 지시문

상태: 2026-11-15 그림 검토(청나라식 복색, 정화의 출신) 반영. 이 파일은 [`prompts/build.py`](prompts/build.py)가 만든다. 직접 고치지 말고 `build.py`를 고친 뒤 다시 만든다. 컷 번호는 [`ep02.md`](ep02.md)를 따른다. 새로 뽑을 그림은 11장이다(설정화 1 + 컷 10).

## 쓰는 법

1. **설정화 B를 먼저 뽑는다.** 각 항목 아래 회색 상자의 글을 통째로 복사해 그림 도구(ChatGPT, 제미나이 등)에 붙여 넣는다. 상자 오른쪽 위의 복사 단추를 누르면 한 번에 복사된다. 상자 안의 글은 "Flat vector-style illustration"으로 시작해 "central 60% of the frame."으로 끝난다. 그림체, 시대 조건, 공통 조건이 이미 들어 있으니 다른 말을 덧붙이지 않아도 된다.
2. 마음에 들 때까지 다시 뽑고, 고른 한 장을 저장한다. 세로나 정사각형으로 나오면 "가로로 긴 그림으로 다시 그려 줘"라고 한 번 더 요청한다.
3. 같은 대화창에서 여러 장을 이어 뽑으면 앞 그림의 잘못(예: 청나라식 옷)이 다음 그림으로 옮겨 갈 수 있다. 시대가 틀린 그림이 한 번 나왔으면 새 대화창에서 다시 뽑는다.
4. 컷 지시문을 차례로 뽑는다. "참고 이미지"에 설정화가 적힌 컷은 그 그림 파일을 먼저 올린 뒤 지시문을 붙여 넣는다.
5. 파일 이름은 `ep02_sheetB.png`, `ep02_c03.png`처럼 컷 번호를 두 자리로 적는다.
6. 뽑은 그림은 GitHub의 `hegemony-video-assets` 브랜치에 `_src/hegemony/video/assets/ep02/` 폴더로 올린다(Add file → Upload files). 시대가 틀리게 나온 그림도 올려 주면 원인을 찾는 데 쓴다.

## 알아 둘 것

- 모든 지시문에 장면의 **시대 조건**(명나라 초, 1490년대 포르투갈, 1498년 캘리컷)이 들어 있다. 중국 장면에는 청나라식(변발, 구슬 달린 모자, 말굽 소매, 조주)을 쓰지 말라는 조건이 붙는다.
- 인물은 이름과 시대로 지칭한다(영락제는 명나라 3대 황제, 정화는 색목인 후손인 회족 무슬림 출신 태감). 얼굴은 상상이다. 영락제와 마누엘 1세는 얼굴을 그리지 않는다.
- 고증은 글 자료만으로 했다. 당시의 그림은 직접 보지 못했다. 근거 번호는 [`research/05-패권-영상-근거.md`](../../../research/05-패권-영상-근거.md)의 항목이다.
- `▶`가 붙은 컷은 나중에 돈을 써서 움직임을 더한다면 먼저 할 컷이다. 지금은 정지 그림만 뽑는다.
