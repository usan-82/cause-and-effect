# 패권의 지도, 사람으로 보기 / hegemony/video 소스

`atlas-simple`의 11장을 인물 열 명의 이야기로 따라가는 3분 영상 시리즈의 콘티와 지시문. 설계는 [`docs/superpowers/specs/2026-11-13-hegemony-video-design.md`](../../../docs/superpowers/specs/2026-11-13-hegemony-video-design.md).

상태: 파일럿(1편) 콘티에 1차 검토를 반영했다. 영상과 공개 페이지는 아직 없다.

## 파일

- `ep01.md` … — 편별 콘티. 검토 대상이다.
- `ep01.prompts.md` … — 그림·영상 지시문. 콘티가 승인된 뒤에 확정한다.
- 사실의 출처는 [`research/05-패권-영상-근거.md`](../../../research/05-패권-영상-근거.md).

## 콘티 읽는 법

컷마다 한 줄이다.

| 칸 | 뜻 |
|---|---|
| 컷 | 번호. 구간(①~⑦)은 설계 문서 4장 |
| 초 | 그 컷의 길이 |
| 종류 | `그림` AI가 그리는 장면 · `지도` atlas-simple 화면을 찍은 것 · `기록` 남아 있는 유물이나 문서를 바탕으로 한 그림 · `카드` 글자가 들어가는 화면(언어별로 따로 만든다) |
| 화면 | 무엇이 보이나. 모든 그림 컷은 정지 그림을 천천히 밀거나 당겨 만든다(무료). `▶`는 돈을 써서 영상 생성 도구로 움직임을 더한다면 먼저 할 컷이다. 없어도 편은 완성된다 |
| 해설 | 읽어 주는 말. 해요체, 한 문장 45자 이내 |
| 근거 | 근거 파일의 항목 번호와 등급(확실·유력·논쟁) |

## 규칙

- 편 첫머리에서 두 인물을 한 문장씩 소개한다. 그림은 설정화에서 잘라 쓴다.
- 그림체는 색 면이 넓고 색 수가 적은 평면 삽화다. 질감과 그러데이션을 쓰지 않는다(용량이 작아진다).
- 인물은 말하지 않는다. 기록에 남은 말만 해설이 출처와 함께 옮긴다.
- 화면에 글자를 굽지 않는다(`카드` 컷 제외). 세 언어가 같은 그림을 쓴다.
- 지도는 AI로 그리지 않는다.
- 해설의 사실은 근거 파일에 있는 것만 쓴다. 등급이 '논쟁'인 내용은 단정하지 않고 "~라는 설명도 있어요"로 쓴다.
- 숫자는 기록에 적힌 숫자인지 학자의 추정인지 구분해 말한다.
