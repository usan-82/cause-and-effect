# 『총, 균, 쇠』 크게 읽기 / guns-germs-steel 소스

『총, 균, 쇠』의 강연 정리(설민석 강독, tvN 「요즘 책방」 6회)와 책 정리를 시력이 나쁜 사람도 휴대폰으로 읽기 좋게 옮긴 판. `ko/guns-germs-steel/`은 모두 이 폴더에서 생성된다.

```
cd _src/guns-germs-steel
node build.mjs        # 의존성 없음
```

- `index.md` — 처음 화면. `:::entry <lecture|book> 제목` 블록이 두 갈래 입구가 된다.
- `lecture.md` · `book.md` — 본문. `# 제목` 하나가 한 쪽이고, 바로 아래 `@@id`(파일 이름 `<lecture|book>-<id>.html`)·`@@where`(책의 자리)·`@@desc`(링크 미리보기 문구)를 둔다. 첫 쪽의 id 는 `intro` 여야 한다.
- 블록: `@이름 대사`(대화), `:::word`(낱말 풀이, `낱말: 풀이`), `:::think`(생각해 볼 질문), `:::flow 제목`(위에서 아래로 가는 사슬, 들여쓴 `- `는 그 칸의 갈래, `!`는 강조 칸), `:::bars 제목`(`라벨 | 값 | 설명`), `:::map`(대륙 모양 그림), `:::card 제목`, `:::details 제목`.
- 원본은 식견 볼트의 `tvn-요즘책방-ep06-총균쇠_ko.md`(2026-11-06)와 `book-총균쇠_ko.md`(2026-11-05). 내용은 그대로 두고 읽는 모양만 바꿨다: 각주는 그 문단 아래 낱말 풀이 상자로, 표는 목록·카드로, mermaid 와 글자 그림은 세로 사슬·막대·SVG 로, 긴 ①②③ 문단은 한 줄씩 나눴다.

## 화면 원칙
- 기본 글자 22px(저장소의 다른 페이지는 17px). 머리의 가−/가+ 단추로 20–34px 여섯 단계, 고른 크기는 그 기기에 남는다.
- 한 장(이야기) = 한 쪽. 쪽 맨 아래의 큰 「다음 쪽」 단추로 넘긴다. 처음 화면에 「읽던 곳 이어 읽기」가 뜬다.
- 가로 스크롤이 생기는 요소(표·코드 블록)를 쓰지 않는다. 각주 위첨자처럼 작은 누름 자리도 쓰지 않는다.
- 밝은 화면·어두운 화면 모두 글자와 바탕의 대비를 높게 잡았다(기기 설정을 따른다).
